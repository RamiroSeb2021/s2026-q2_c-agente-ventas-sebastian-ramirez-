# Checklist de Redacción Académica — Nivel Maestría

## Estructura
- [ ] El problema está definido con claridad
- [ ] El objetivo responde al problema
- [ ] La pregunta o hipótesis está bien delimitada
- [ ] El aporte del trabajo aparece explícitamente
- [ ] Las secciones siguen una secuencia lógica

## Argumentación
- [ ] Cada afirmación importante tiene sustento
- [ ] No hay saltos lógicos entre párrafos o secciones
- [ ] La revisión de literatura sintetiza, no enumera
- [ ] Las conclusiones se desprenden del análisis
- [ ] No se sobrepromete impacto o novedad

## Estilo
- [ ] El tono es formal pero legible
- [ ] No hay relleno ni frases infladas
- [ ] Los párrafos tienen idea central clara
- [ ] Se usan conectores con función real
- [ ] La terminología es consistente

## Método y evidencia
- [ ] El método es coherente con el objetivo
- [ ] La evidencia usada es suficiente para sostener los claims
- [ ] Se distinguen resultados, interpretación y opinión
- [ ] Las limitaciones están reconocidas con honestidad

## Integridad académica
- [ ] No hay citas inventadas
- [ ] No hay autores o resultados no verificados
- [ ] Las referencias faltantes están marcadas
- [ ] El texto evita plagio y paráfrasis demasiado cercana
