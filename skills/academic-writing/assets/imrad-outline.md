# IMRaD Outline — Academic Writing

## Abstract
- problema
- objetivo
- método
- resultado principal
- conclusión

## Introduction
- contexto general
- problema específico
- brecha de conocimiento o de aplicación
- objetivo o pregunta
- aporte esperado

## Literature Review / Theoretical Background
- organizar por ejes temáticos, no por lista de autores
- mostrar consensos
- mostrar tensiones
- mostrar vacíos
- conectar con el trabajo propio

## Methods
- unidad de análisis
- datos o corpus
- procedimiento
- variables o categorías
- técnica analítica
- limitaciones metodológicas

## Results
- reportar hallazgos de forma ordenada
- no mezclar interpretación fuerte con resultados crudos
- usar tablas/figuras solo si agregan claridad

## Discussion
- interpretar hallazgos
- conectar con literatura
- explicar implicaciones
- reconocer limitaciones
- proponer líneas futuras

## Conclusion
- resumir aporte real
- evitar repetir el abstract
- no inflar conclusiones
