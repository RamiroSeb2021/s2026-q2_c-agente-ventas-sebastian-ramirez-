# Descriptive Commit Body Template

Use short bullets or compact paragraphs. Include every applicable section.

```text
Created:
- <new files, modules, contracts, tests, docs, or workflows>

Modified:
- <existing behavior/files changed and how>

Removed:
- <deleted/deprecated behavior, files, or fields>

Purpose:
- <why this change exists; user value, technical reason, or workflow boundary>

Verification:
- <tests, commands, manual checks, or "not run" with reason>
```

Prefer explaining the work unit over listing every file mechanically. Keep the title short; put detail here.
